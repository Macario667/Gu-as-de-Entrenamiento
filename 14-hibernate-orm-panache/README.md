# 14 · Hibernate ORM with Panache

Guía oficial de referencia: [Hibernate ORM with Panache](https://quarkus.io/guides/hibernate-orm-panache).

Este proyecto parte de la guía 13 y conserva los ejemplos de las guías 01–13. La dependencia de Hibernate ORM with Panache y los paquetes para entidades y repositorios están preparados, pero no hay entidades, repositorios ni operaciones de persistencia implementadas: ese contenido queda para el estudio de esta guía.

## Requisitos y ejecución

Se requiere JDK 17 o compatible con `maven.compiler.release` y Maven instalado. Este proyecto no incluye Maven Wrapper.

Desde PowerShell, entra en esta carpeta e inicia Quarkus:

```powershell
Set-Location "C:\Users\Samu\OneDrive\Desktop\Guías de Entrenamiento\14-hibernate-orm-panache"
mvn quarkus:dev
```

Los ejemplos heredados de las guías anteriores siguen disponibles. La configuración de datasource se conserva como base; la configuración y el uso de Hibernate ORM with Panache quedan pendientes de estudio e implementación.
